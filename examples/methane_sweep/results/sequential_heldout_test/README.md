# Sequential held-out methane test results

These tables are transcribed from completed training-log `Testing model...`
sections. For 1M training runs, the test set is the 80,000 sequential methane
frames `[1,000,000, 1,080,000)`.

This is distinct from `results/external_test/`, whose newer evaluations use
the reserved random common-test indices in
`test_sets/methane_common_test_n80000_seed20260720.npy`.
